# CPS AI Audit

Web App สำหรับตรวจประเมินระบบการผลิต **CPS Health Check (ระดับหัวหน้าทีม / หัวหน้ากลุ่ม)** และ **KUP** ของ Rayong Plant
ใช้งานได้บนมือถือ แท็บเล็ต และโน้ตบุ๊กจาก Web App เดียว ไม่ต้องติดตั้งแอป

ระบบทำงานบน **Google Apps Script** โดยใช้ Google Sheets เป็นฐานข้อมูล, Google Drive (โฟลเดอร์ส่วนตัว) เก็บหลักฐาน และใช้ **Gemini** หรือ OpenAI วิเคราะห์หลักฐาน

> ระบบนี้ไม่มีไฟล์มาตรฐาน Excel หรือหลักฐานการออดิทใน repository
> และ API Key ถูกเก็บไว้ใน Script Properties ฝั่งเซิร์ฟเวอร์เท่านั้น

## Flow การใช้งาน

```
นำเข้ามาตรฐาน (Excel) → ตรวจทาน/ตัดสินจุดที่ไม่ชัด → ประกาศใช้
   → สร้างรอบออดิท → เดินตามเส้นทางการออดิท → แนบหลักฐาน (ภาพรวม/ภาพซูม/เสียง/เอกสาร/บันทึก)
   → วิเคราะห์ด้วย AI → ผู้ตรวจทบทวน/ยืนยันรายข้อ → ระบบคำนวณคะแนนตามเกณฑ์
   → ยืนยันรอบตรวจ → Dashboard + ติดตามปัญหา (แก้ไข → ตรวจยืนยันประสิทธิผล → ปิด)
```

## ความสามารถหลัก

| ส่วน | สิ่งที่ทำ |
|---|---|
| นำเข้ามาตรฐาน | อ่าน `.xlsx` เองโดยไม่ใช้ไลบรารีภายนอก รองรับ merged cells และข้อความไทย/จีน เก็บชื่อไฟล์ ชีต และเซลล์ต้นทาง แยกกฎหักคะแนน ช่วงคะแนน น้ำหนัก Red Line และจำนวนตัวอย่าง ข้อมูลที่ไม่ชัดจะติดป้าย "ต้องตรวจทานเกณฑ์" ถ้าพบชีตคล้ายกัน (เช่น KUP กับ KUP (2)) จะแสดงความต่างให้เลือกเอง ไม่รวมให้อัตโนมัติ |
| เวอร์ชันมาตรฐาน | มีขั้นตอนร่าง → ประกาศใช้ → เลิกใช้ ฉบับที่ประกาศแล้วแก้ไขไม่ได้ ถ้าต้องแก้ให้ Clone เป็นฉบับใหม่ ผลออดิทย้อนหลังจึงไม่เปลี่ยน |
| เส้นทางการออดิท | แยกตามประเภทการตรวจและเวอร์ชันมาตรฐาน แบ่งเป็นจุดตรวจ (ประชุม / บอร์ด / ตำแหน่งงาน / เอกสาร / สัมภาษณ์) เข้าตรวจทีละจุดได้หลายช่วงเวลา บังคับว่าทุกข้อต้องอยู่ในเส้นทาง และนับจำนวนตัวอย่างให้อัตโนมัติ |
| หลักฐาน | ถ่ายภาพจากกล้องได้ทันที ภาพซูมเชื่อมกับภาพรวม บันทึกเสียงแล้วถอดเสียงพร้อมเวลา (แก้ข้อความได้ และกดเวลาเพื่อย้อนฟังได้) แนบ PDF ได้ หลักฐานหนึ่งชิ้นใช้ได้หลายข้อ วิดีโอเก็บได้แต่แจ้งชัดว่ายังวิเคราะห์ไม่ได้ |
| AI | ส่งผลเป็น JSON ตาม schema แยกข้อเท็จจริง คำกล่าว และข้อสันนิษฐาน ระบบตรวจ `rule_id` และ `evidence_id` ทุกครั้ง ถ้าไม่ผ่านจะไม่นำผลมาใช้ กันการกดซ้ำและจำกัดความถี่การเรียก และการลองใหม่ไม่สร้างปัญหาซ้ำ |
| ตรวจทีละทีม | ปุ่ม **จดเร็ว** ถ่ายรูปแล้วจดสั้น ๆ หรือติ๊ก "เป็นปัญหา" ได้โดยไม่ต้องเลือกข้อก่อน รูปที่จดไว้ไปรอในถาด **รอจัดเข้าข้อ** ให้ AI แนะนำข้อแล้วกดยืนยันทีเดียว และระบบสร้างร่าง issue ให้เอง เปิดรอบตรวจแล้วจะเห็น **ประเด็นครั้งก่อนของทีมนั้น** (ข้อที่เคยพบติดป้าย "เคยพบ") มีตัวกรอง **ควรดูก่อน** สำหรับตอนเวลาน้อย และปุ่ม **ตรวจทีมถัดไป** |
| คะแนน | Scoring engine แยกจาก AI โดยสิ้นเชิง ปัญหาเดียวกันหักครั้งเดียว กฎที่ไม่ชัดจะทำให้คะแนนสุดท้ายถูกระงับ หลักฐานไม่พอไม่นับเป็น 0 หรือผ่าน คะแนนชั่วคราวแสดงแยกจากคะแนนสุดท้าย และการแก้คะแนนต้องระบุเหตุผล |
| หลายอุปกรณ์ | บันทึกร่างอัตโนมัติ ถ้าออฟไลน์จะเก็บข้อมูลในเครื่องแล้วส่งให้เองเมื่อกลับมาออนไลน์ มีเลขเวอร์ชันกันการแก้ไขทับกัน และหมุนจอแล้วข้อมูลที่กรอกไม่หาย |
| รายงาน | Excel คะแนนรายข้อ, Excel รายการปัญหา และ PDF สรุปรอบตรวจ ทุกไฟล์ระบุว่าเป็นร่างหรือยืนยันแล้ว รวมถึงวันที่ เวอร์ชันมาตรฐาน และขอบเขต |

## โครงสร้าง

```
src/
  appsscript.json        manifest (Web App ทำงานในนามบัญชีผู้ deploy)
  shared/                โค้ดบริสุทธิ์ ใช้ได้ทั้ง Apps Script และทดสอบบน Node
    XlsxReader.js        อ่าน .xlsx (merged cells, shared strings, formulas)
    StandardParser.js    แปลงชีตเป็นข้อกำหนด/กฎ/Red Line/เส้นทาง/ป้ายตรวจทาน
    Scoring.js           scoring engine
    AiSchema.js          schema และการตรวจผล AI, system prompt
    Permissions.js       สิทธิ์ตามบทบาท
    DashboardCalc.js     การคำนวณ Dashboard
  server/                API ฝั่ง Apps Script (Db, Auth, Standards, Audits, Evidence, Ai, Findings, Dashboard, Reports, Setup)
  client/                index.html, styles.html, js/*.js (หน้าจอทั้งหมด)
scripts/build.mjs        สร้าง dist/ สำหรับ clasp และ dist-preview/ สำหรับทดสอบ UI
scripts/dev-server.mjs   เซิร์ฟเวอร์จำลองในเครื่อง (รันโค้ดเซิร์ฟเวอร์จริงบน Apps Script จำลอง)
test/                    node:test — นำเข้า, คะแนน, สิทธิ์, schema AI, Dashboard, flow ครบวงจร
docs/                    DEPLOY.md, ARCHITECTURE.md, TEST-REPORT.md
```

## เริ่มต้นใช้งาน

ดูขั้นตอนเต็มที่ [docs/DEPLOY.md](docs/DEPLOY.md) สรุปสั้น ๆ:

```bash
npm run build
npx @google/clasp login
cp .clasp.json.example .clasp.json   # ใส่ scriptId
npx @google/clasp push
# ใน Apps Script: ตั้ง Script Property ADMIN_INITIAL_PASSWORD แล้วรัน setup()
# Deploy → New deployment → Web app (Execute as: Me, Who has access: Anyone)
```

## ทดสอบ

```bash
npm test                                   # เทสต์ที่ไม่ใช้ไฟล์มาตรฐานจะรันเสมอ
CPS_STANDARD_DIR=./standards-local npm test   # เพิ่มเทสต์นำเข้าและ flow กับไฟล์จริง
npm run dev                                # เปิด http://localhost:8787 (admin / Admin12345)
```

ผลทดสอบล่าสุดและส่วนที่ยังไม่ได้ทดสอบอยู่ที่ [docs/TEST-REPORT.md](docs/TEST-REPORT.md)

## ข้อจำกัดที่ควรทราบ

- **Google Sheets ไม่ใช่ฐานข้อมูลเชิงสัมพันธ์:** ระบบบังคับ foreign key และเวอร์ชันในโค้ด และใช้ LockService ร่วมด้วย การยืนยันรอบตรวจทำภายใต้ lock เดียว โดยเขียนสถานะ "ยืนยันแล้ว" เป็นขั้นตอนสุดท้าย ถ้าล้มกลางทางจะลองใหม่ได้โดยไม่เกิดข้อมูลซ้ำ แต่ไม่มี rollback อัตโนมัติ เหมาะกับข้อมูลระดับหลายหมื่นแถว
- **ขนาดไฟล์และเวลา:** ภาพจำกัด 10 MB (ระบบย่อภาพก่อนอัปโหลด), เสียงและ PDF 15 MB, วิดีโอ 25 MB และสคริปต์แต่ละครั้งรันได้ไม่เกิน 6 นาที
- **Gemini แบบฟรี:** Google อาจนำข้อมูลที่ส่งไปใช้ปรับปรุงบริการ ควรตรวจกับ IT ก่อนใช้กับภาพหน้างานจริง
- **ออฟไลน์:** บันทึกร่างและอัปโหลดหลักฐานจะรอส่งให้เอง แต่การวิเคราะห์ด้วย AI ต้องใช้อินเทอร์เน็ต
- **ยังไม่รองรับในรุ่นนี้:** ชีต QOS/MOS/COS/DOS (โครงสร้างช่วงคะแนนต่างจาก KUP), ระดับ Manager (นำเข้าได้แต่ยังไม่เปิดใช้ออดิท) และการวิเคราะห์วิดีโอ
