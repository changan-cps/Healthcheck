## 2. ทดสอบหน้าจอ (Playwright + Chromium ในเครื่องทดสอบ)

**จำลองขนาดจอเท่านั้น ยังไม่ได้ทดสอบบนอุปกรณ์จริง**

- **การล้นแนวนอน:** วัด `scrollWidth − innerWidth` ที่ 360, 390, 768, 1024 และ 1366 px บนหน้าภาพรวม, รายการรอบตรวจ, สร้างรอบตรวจ, ปัญหา, คลังมาตรฐาน, ตั้งค่าผู้ใช้, หน้าตรวจ, สรุปคะแนน และหน้าเวอร์ชันมาตรฐาน → **0 px ทุกหน้า ทุกขนาด** ส่วนตารางใหญ่เลื่อนได้ภายในตารางเอง
- **มือถือ 390 px:**
  - สร้างรอบตรวจ → stepper มาตรฐาน/หลักฐาน/ผล AI/คะแนน → แนบภาพผ่านช่องเลือกไฟล์ของกล้อง → พิมพ์บันทึกแล้วบันทึกอัตโนมัติ ("บันทึกแล้ว")
  - กดวิเคราะห์ (AI จำลอง) → "ใช้ผลนี้เป็นร่างคะแนน" → คำนวณ 10 − 3 = 7 → ยืนยันข้อ
- **ออฟไลน์ (เซิร์ฟเวอร์จำลองตอบ 503):** สถานะแสดง "บันทึกไม่สำเร็จ — เก็บไว้ในเครื่อง จะส่งเมื่อออนไลน์" เมื่อกลับมาออนไลน์ระบบส่งเองและแสดง "บันทึกแล้ว"
- **หมุนจอ:** แท็บเล็ต 768×1024 → 1024×768 ข้อความที่กรอกในช่องเหตุผลยังอยู่ครบ
- **จดเร็ว:** ถ่าย 2 รูป (1 รูปติ๊กเป็นปัญหา) → ถาดรอจัดเข้าข้อ → AI แนะนำ → ยืนยันทั้งหมด → ถาดว่าง และสร้างร่าง issue → ตัวกรอง "ควรดูก่อน" → สรุปคะแนน → "ตรวจทีมถัดไป: Team Side Panel B" เติมค่าให้ถูกต้อง
- **ข้อผิดพลาด JavaScript:** ไม่พบเลย ส่วนฟอนต์ Sarabun โหลดไม่ได้ในเครื่องทดสอบเพราะไม่มีอินเทอร์เน็ต จึงใช้ฟอนต์สำรองแทน

## 3. สิ่งที่ยังไม่ได้ทดสอบ (ต้องทำหลัง deploy จริง)

| รายการ | เหตุผล |
|---|---|
| **การเรียก AI จริง (Gemini / OpenAI)** | ยังไม่มี API Key ในสภาพแวดล้อมนี้ เทสต์ใช้ HTTP จำลองที่ตอบรูปแบบเดียวกับ Gemini จึงยืนยันได้แค่ request/validation/การจัดการข้อผิดพลาด แต่ยังไม่ได้ยืนยันคุณภาพผลวิเคราะห์ภาพ เสียง และ PDF จริง หลังใส่คีย์ให้กด "ทดสอบการเชื่อมต่อ" แล้ววิเคราะห์ภาพหน้างานจริง 3–5 ข้อ |
| **รันบน Google Apps Script จริง** | ยังไม่ได้ push (ไม่มีสิทธิ์ clasp ในสภาพแวดล้อมนี้) โค้ดเซิร์ฟเวอร์ผ่านการทดสอบบน Apps Script จำลอง ส่วนที่ต้องลองบนของจริง: `Utilities.unzip` กับไฟล์ xlsx, ความเร็ว Sheets เมื่อข้อมูลมาก, export Excel ผ่าน Drive URL, PDF จาก HtmlService |
| **อุปกรณ์จริง** | Safari บน iPhone/iPad (กล้อง, MediaRecorder เป็น audio/mp4), Chrome/Edge บน Android/Windows ยังไม่ได้ทดสอบบนเครื่องจริง และยังไม่ได้ทดสอบการล็อกจอระหว่างบันทึกเสียงบนอุปกรณ์จริง (ในโค้ดหยุดที่ `visibilitychange`/`pagehide`) |
| **ผู้ใช้พร้อมกันหลายคน** | LockService ทดสอบแบบจำลองเท่านั้น |
